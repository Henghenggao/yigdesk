## 0:00-0:20 - Problem

“A discount request arrives in email, but the decision lives across an attachment, formulas, and policy. Most agents can draft an answer. Yigdesk shows the consequence and the evidence before an agent acts.”

## 0:20-1:05 - Complete evidence

Open **Complete evidence** and select **Analyze with Codex**.

“The source stays untouched. The preview shows $880k net ARR, a $20k decrease, 45.5% gross margin, and 5.5 points above the floor. These are packet values, not browser arithmetic.”

Point to <code>Workbook bytes unchanged</code>, the five highlighted objects, and the source fingerprint. Select <code>Deal Model!B4</code> and show its formula, precedents, and dependent.

## 1:05-1:35 - Honest refusal

Switch to **Missing cost evidence** and analyze again.

“Cost is absent, so margin cannot be proven. Yigdesk reports <code>HOLD</code>, displays <code>Unavailable</code>, and withholds the memo. The refusal is live, not a slide.”

## 1:35-2:05 - Codex and product boundary

“Codex helped implement and test the full experience, then challenged the weak claims: read-only needed byte proof and HOLD needed a runnable fixture. This public repo exposes the read-only session and inspectors, while the proprietary Yigrid kernel and commercial trust layer are not included.”
